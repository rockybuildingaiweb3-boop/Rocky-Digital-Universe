## 🌟 Core Philosophy

> **"It is not a portfolio. It is my Personal Operating System."**  
> *「它不是一个 Portfolio，它应该是：My Personal Operating System。」*

Traditional portfolios are static trophies of the past. **Rocky's Digital Universe** is an evolving digital habitat designed to grow with life over the next decade.

### The Six Core Systems:
1. **`01 — Identity System` (Who I Am)**: Biography, origin story, values, and formative timeline.
2. **`02 — Capability System` (What I Can Build)**: Bento-grid of real-world execution, technical architectures, and delivered business impact.
3. **`03 — Knowledge System` (What I Learn)**: Curated mental models, system blueprints, and deep essays.
4. **`04 — Laboratory System` (Where Ideas Experiment)**: AI Studio prompts, multi-agent workflows, and prototype tools.
5. **`05 — Connection System` (Connecting with People)**: Frictionless global outreach bridging international channels with direct WeChat (微信) QR connectivity for Chinese partners.
6. **`06 — Growth System` (Recording the Journey)**: Chronological life and engineering changelog (2024–2034).

## ⚡ Quick Start

No package manager or build step required. Open the application directly:

```bash
# Option 1: Using Python 3 HTTP Server
python -m http.server 8080

# Option 2: Using Node.js npx serve
npx serve .

# Option 3: Double click index.html directly in any modern browser
```

Visit `http://localhost:8080` to access the system.

## 🌐 Bilingual Demonstration (How it works)
- **Default Experience**: 100% fluent, international-grade English.
- **Client Presentation Mode**: Click the **`[ 简体中文 ]`** toggle in the top navigation bar. The entire interface immediately switches into clear, professional Chinese without page reload, allowing Rocky to walk Chinese clients through every concept and capability seamlessly.
